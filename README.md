# CS_Gallery_Fullstack

Art portfolio / gallery website developed in HTML, CSS, and JavaScript.

## Overview
This project gathers several pages showcasing my visual work:
- illustrations
- character design
- pixel art
- sketches and exploratory work
- personal graphic universes

## Structure
- `index.html` : main page
- `style.css` : main stylesheet
- `Scripts/script.js` : JavaScript scripts
- `images/` : visual assets

## Technologies
- HTML5
- CSS3
- JavaScript

## Objective :
Develop a versatile gallery website with multiple sections to showcase artistic works (online portfolio) or products for an e-commerce store, demonstrating my skills as a full-stack developer and enriching my professional portfolio.

The project may evolve into a more dynamic version with:
